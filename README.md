# Madoka Thomson — Portfolio

A responsive GitHub Pages portfolio for bilingual technical support, implementation, and data roles.

## Publish with GitHub Pages

1. Merge the portfolio pull request into main.
2. Open **Settings → Pages** in this repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the main branch and / (root), then select **Save**.

The site will be available at https://sonokoala.github.io/Madoka-s-site/ after GitHub finishes deployment.
